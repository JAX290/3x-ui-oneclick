# 08 · 从零重建（面板被改乱 / 节点被删光）

> 适用：面板设置改乱了、入站/客户端删没了、链接还是 `localhost`。
> 两条路：**A 一键重装（推荐）**、**B 手动逐步（想学原理）**。

---

## 路线 A：一键重装（最稳，5–8 分钟）

```bash
bash <(curl -Ls https://raw.githubusercontent.com/JAX290/3x-ui-oneclick/main/scripts/install.sh) --reinstall
```

它会做（顺序固定）：

| 步骤 | 动作 | 结果 |
|---|---|---|
| 1 | 卸载旧面板（`/etc/x-ui`、`/usr/local/x-ui`） | 之前改乱的设置全部清空 |
| 2 | 重新安装 3x-ui | 随机用户名/密码/端口/访问路径 |
| 3 | 创建 VLESS + REALITY 入站（含分享地址=公网 IP） | 链接里不会再出现 `localhost` |
| 4 | 创建客户端 `user1`（flow=xtls-rprx-vision） | 可直接扫码 |
| 5 | 关闭面板广告 | 登录页/仪表盘无赞助位 |
| 6 | 下载客户端安装包并开下载页 | 手机不连 GitHub 也能装 App |
| 7 | 打印面板地址、节点链接、二维码 | 保存到 `/root/3xui-info.txt` |

结束标志：屏幕出现「部署完成！」+ 二维码。

> 你之前的节点/客户端已删光，重装不会丢有用的东西。

---

## 路线 B：手动从零（约 20 分钟，能搞懂每一项）

### B1. 先把面板设置恢复干净

面板本身也要先能正常访问。设置乱了用 CLI 重置（**账号密码不会变**）：

```bash
x-ui setting -reset                      # 面板设置恢复默认（端口/路径/证书/订阅等）
x-ui setting -port 54321 \
             -webBasePath mypath123456 \
             -username myadmin \
             -password 'MyStrongPass2026!'   # 立刻改成随机值，别用默认
systemctl restart x-ui
```

**每步作用**：

- `-reset`：把面板的端口、路径、证书、订阅、时区等设置恢复官方默认值（账号数据保留）
- `-port` / `-webBasePath`：默认端口 2053、路径 `/` 是扫描器首选目标，换随机值等于加一道门
- `-username` / `-password`：安装脚本生成的都是随机值，你自己设就自己记得住
- `restart`：设置写入数据库，需重启生效

然后访问：`http://你的IP:54321/mypath123456`

### B2. 创建入站（Inbound = 一个“监听端口 + 协议”的入口）

面板 → 左侧「**入站**」→ 右上「**添加入站**」，按下表填：

| 字段 | 填什么 | 作用 |
|---|---|---|
| 备注 | `oneclick-reality` | 自己认得出的名字 |
| 协议 | `vless` | 现代协议，配合 REALITY 最稳 |
| 监听端口 | `443` | 客户端连的端口 |
| 传输协议 | `RAW`（旧版叫 `tcp`，v3.11 改名为 RAW） | REALITY 只支持 TCP/RAW |
| 安全 | `reality` | 借用真实网站证书伪装，不需要域名/证书 |
| 目标(dest) | `www.microsoft.com:443` | 伪装对象，要支持 TLS1.3 + HTTP/2 |
| SNI | `www.microsoft.com` | 必须与目标站域名一致 |
| 私钥/公钥 | 点「获取」自动生成 | REALITY 密钥对；私钥留在服务器 |
| shortId | 点「获取」自动生成 | 客户端身份校验用 |
| 流控 flow | `xtls-rprx-vision` | 配合 REALITY 的加速/抗探测模式 |
| 嗅探 | 保持开启 | 让 Xray 识别域名，路由更准 |

保存后，入站列表会出现这条（绿色=启用）。

### B3. 加客户端（Client = 使用这条入站的身份）

入站列表 → 点这条入站的「**客户端**」→ 添加：

| 字段 | 填什么 | 作用 |
|---|---|---|
| 名称/邮箱 | `user1` | 客户端标识，流量按它统计 |
| ID(UUID) | 点生成 | 客户端身份，等于账号 |
| 流控 | `xtls-rprx-vision` | 与入站保持一致，否则握手失败 |
| 剩余流量 / 到期 | 留空或 0 | 0 = 不限制 |
| IP 限制 | `0` | 0 = 不限制；想防共享可填 1~2 |
| 订阅 ID | 自动生成，留着 | 以后要用订阅链接时用 |

### B4. 填「分享地址」（关键，别跳过）

编辑这条入站 → 找到「**分享地址 / Share Address**」→ 填 **你的公网 IP**（如 `216.36.85.213`）→ 保存。

> 作用：面板自己不知道公网 IP，不填就会生成 `vless://...@localhost:443`，
> 手机导入后点启动会报「无效的配置」。填了之后面板里的二维码、分享链接、订阅链接才正确。

### B5. 生成链接 / 二维码

客户端列表 → 点该客户端旁的「二维码」或「复制链接」。链接应形如：

```text
vless://<uuid>@216.36.85.213:443?type=tcp&security=reality&encryption=none&
pbk=<公钥>&fp=chrome&sni=www.microsoft.com&sid=<shortId>&flow=xtls-rprx-vision#oneclick-reality
```

检查点：`@` 后面必须是 **IP:端口**，不能是 `localhost` / `127.0.0.1` / 空。

### B6. 手机导入

v2rayNG →「配置」页 → `+` →「从剪贴板导入」或扫码 → 选中节点 → 点 `V` 启动。
（这是**单条配置**，不要粘到「订阅」里。）

### B7. 验证

- 客户端显示已连接
- 浏览器打开 `https://ip.sb` → 显示你的 VPS IP
- 服务器上：`systemctl status x-ui` 正常、`ss -lntp | grep :443` 有监听

## 面板设置项：哪些该动、哪些别动

| 设置项 | 建议 | 说明 |
|---|---|---|
| 面板端口 / 访问路径 | **改**成随机值 | 防扫描；改完记得重启并记下来 |
| 用户名 / 密码 | **改**成强密码 | 默认随机值太难记就自己设 |
| 面板监听 IP | 保持 `0.0.0.0` | 改 `127.0.0.1` 后外网打不开（除非用 SSH 隧道） |
| 证书 / SSL | **不要开** | REALITY 不需要证书；开了反而容易把面板弄挂 |
| 订阅服务 | 自用可不启用 | 需要多设备同步再开 |
| 时区 | `Asia/Shanghai` | 只影响日志/到期时间显示 |
| 2FA 两步验证 | 可选 | 开了要用验证器 App，别忘备份 |
| 分享地址（每个入站） | **必填公网 IP** | 不填 = `localhost` 链接 = 无效配置 |
| 流量统计 | 保持默认 | 不影响使用 |

## 常见错误对照

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动报「无效的配置」 | 链接地址是 `localhost`/空 | B4 填分享地址，或重新生成链接 |
| 导入后「订阅」为空 | 把单条配置当订阅 | 用「配置 → 从剪贴板导入」 |
| 面板打不开 | 改端口/路径后忘了，或证书坏 | `x-ui setting -show true` 看实际端口/路径 |
| 端口 443 被占用 | 装了别的 web 服务 | 换 8443 并放行 |
| 连上但没网 | 规则模式/时间不同步 | 先全局模式；`date` 校准时间 |
| REALITY 握手失败 | dest 不可达或时间差大 | 换 `www.apple.com:443` 等目标 |

## 收尾

```bash
# 备份（含节点、账号、流量）
tar czf /root/3xui-backup-$(date +%F).tar.gz /etc/x-ui

# 重启 / 看状态 / 再看信息
systemctl restart x-ui
bash /root/info.sh
```

> 记住一句话：**只有「分享地址」必须手动填 IP，其它设置尽量别碰**。
