# 01 · 买一台合适的 VPS

> 目标：花最少的钱买到「能跑、能连、不被坑」的机器。
> 已经买好了可以跳到 [02-connect-vps.md](02-connect-vps.md)。

---

## 1. 到底需要什么配置

| 项目 | 最低 | 建议 | 说明 |
|---|---|---|---|
| CPU | 1 核 | 1 核 | 代理不吃 CPU |
| 内存 | 512 MB | 1 GB | 面板 + Xray 大约占 150–250 MB |
| 硬盘 | 5 GB | 10 GB | 只存配置和日志 |
| 带宽/流量 | 500 GB/月 | 1 TB/月 | 看视频会很快吃完 |
| 架构 | **KVM** | KVM | OpenVZ/LXC 部分功能受限 |
| 系统 | Debian 12 | Debian 12 / Ubuntu 22.04+ | 本脚本主测环境 |

> 结论：**1 核 1G、月流量 1T、KVM、Debian 12** 是最省心的组合，通常每月几美元。

---

## 2. 机房怎么选

代理速度取决于 **VPS 到你家的线路质量**，不是 VPS 本身的配置。

- **优先**：日本、韩国、新加坡、香港（延迟低，但贵、容易被重点照顾）
- **次选**：美国西海岸（洛杉矶/圣何塞，便宜，晚高峰可能绕路）
- **不建议**：欧洲（延迟 200ms+，网页能开但视频卡）

判断方法（买之前看商家测试 IP）：

```bash
# 在你自己的电脑上执行（Windows PowerShell 也可以）
ping 测试IP
```

- 延迟 < 100ms：很好
- 100–180ms：可接受
- > 200ms：除非只用来查资料，否则别买

---

## 3. 买之前必看的 5 个坑

1. **架构不是 KVM** → 买前在商家页面确认写的是 KVM，不是 OpenVZ。
2. **IP 已经被墙** → 有些便宜机器是「回收 IP」。买前问客服能否换 IP、是否额外收费。
3. **流量虚标 / 超量停机** → 看清楚是「单向」还是「双向」计费。
4. **禁止代理** → 少数商家 ToS 明确禁止，买了可能被停机。下单前看一眼条款。
5. **不支持退款** → 先买最短周期（月付）试，别一上来买年付。

---

## 4. 付款与开通后你会拿到什么

一般会收到一封邮件，里面至少有三样东西：

```
IP 地址      : 203.0.113.10
root 密码    : xxxxxxxx
SSH 端口     : 22（有的商家会改，比如 2222）
系统         : Debian 12
```

**这四样请立刻保存到本地记事本**，后面连接服务器要用。

> 有的商家默认只给密钥登录，那就下载它提供的 `.pem` / 私钥文件。

---

## 5. 开通后第一件事：重装成干净的 Debian 12

很多商家默认装的是带面板的镜像。建议在控制台里「重装系统」→ 选 **Debian 12 (64bit)**，勾选「使用密码登录」或「使用 SSH 密钥」。

重装后等 1–2 分钟，用新密码重新登录。

---

## 6. 一个小检查：这台机器有没有外网

登录服务器后（方法见 02），执行：

```bash
curl -I https://www.google.com
```

- 出现 `HTTP/2 200` 或 `HTTP/1.1 200` → 机器能直接上外网，说明 IP 没被墙，可以继续
- 一直卡住 / `Connection timed out` → **这个 IP 已经被墙或没外网**，先去商家后台换 IP，否则后面全白做

---

## 7. 常见疑问

**Q：一定要买域名吗？**
不用。本方案用 VLESS + REALITY，服务端不需要证书，靠「借用」真实网站（如 microsoft.com）的 TLS 握手来伪装，所以没有域名也能跑。

**Q：一定要备案吗？**
不需要，服务器在境外，不涉及备案。

**Q：可以买国内的服务器吗？**
不行。本方案的目的就是访问境外网络，国内机房无法实现。

**Q：年付便宜很多，能买吗？**
第一次用建议月付，确认线路和稳定性后再考虑长期。
